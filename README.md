## ◈ What is RepoLens?

RepoLens is a native Android application designed to make exploring GitHub repositories easier, faster, and more convenient on mobile devices.

From understanding a project's purpose to browsing its source files, checking releases, and downloading available APK assets, RepoLens brings essential repository exploration features into one focused interface.

No need to wrestle with a desktop-oriented layout just to find what you're looking for.

---

## ✦ Explore More. Switch Less.

<table>
<tr>
<td width="50%" valign="top">

### ⌕ Repository Explorer

Explore public GitHub repositories using repository URLs or owner/repository shorthand.

### ◉ Project Overview

View repository descriptions, statistics, languages, ownership information, and README content.

### ⌘ Source Code Browser

Navigate folders, inspect files, and read supported text-based source code directly in the app.

</td>
<td width="50%" valign="top">

### ⇩ Release Discovery

Browse published releases, release notes, and downloadable assets.

### ◇ APK Downloads

Download available APK release assets directly to your Android device.

### ▣ Download Library

Track downloads, monitor progress, manage downloaded files, and open supported files for installation.
